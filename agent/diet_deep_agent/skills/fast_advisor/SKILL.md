# Fasting Advisor Skill

## Purpose
Generate fasting plans, checkin feedback, refeed guidance, and contraindication screening for light fasting (16:8, 5:2, basic bigu).

## Inputs
- User profile (BMI, health conditions, goals)
- Plan type (16_8, 5_2, basic_fasting)
- Checkin data (weight, feeling)

## Outputs
- Structured fasting plan with eating window
- Checkin feedback with risk warnings
- Refeed guidance with phased food recommendations

## Compliance
- MUST screen for contraindications (pregnancy, diabetes, eating disorders, BMI<18.5, minors)
- MUST include stop-on-discomfort warning
- MUST include mandatory disclaimer
- MUST recommend consulting a doctor before starting
