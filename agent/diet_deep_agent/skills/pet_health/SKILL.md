# 宠物健康技能

## 触发条件
- 用户询问宠物健康问题（"我的猫今天吃得够吗"）
- 用户查询宠物档案或体重趋势
- 用户请求宠物营养建议
- 用户上传宠物照片进行分析

## 执行流程

### 1. 识别宠物
- 使用 `get_pet_profile` 获取宠物档案
- 如果用户有多只宠物，询问具体是哪一只

### 2. 收集数据
- 使用 `get_pet_weight_trend` 获取体重趋势
- 使用 `get_pet_feeding_records` 获取饮食记录
- 读取 `/memories/pet_health/{pet_id}.md` 获取宠物健康记忆

### 3. 分析健康状态
- 根据品种/年龄/体重计算营养目标
- 对比当日摄入与目标
- 检查体重变化趋势（异常增重/减轻）

### 4. 生成建议
- 包含兽医免责声明："我是AI助手，建议仅供参考，宠物健康问题请咨询专业兽医"
- 不提供药物推荐或诊断结论
- 遇到"呕吐、腹泻、不吃不喝超过24小时"等关键词，强制建议立即就医

## 输出格式
```
### 🐱 宠物健康报告：{宠物名}

#### 基本信息
- 品种：{品种}
- 年龄：{年龄}岁
- 当前体重：{体重}kg（理想范围：{理想范围}）
- 体重状态：{正常/偏重/偏轻}

#### 今日营养摄入
| 营养素 | 已摄入 | 目标 | 达成率 |
|--------|--------|------|--------|
| 热量   | X kcal | Y kcal | Z% |
| 蛋白质 | X g    | Y g    | Z% |

#### 健康建议
- [具体建议1]
- [具体建议2]

---
⚠️ 免责声明：我是AI助手，建议仅供参考，宠物健康问题请咨询专业兽医。
```

## 可用工具
- `get_pet_profile` - 获取宠物档案
- `get_pet_weight_trend` - 获取体重趋势
- `get_pet_feeding_records` - 获取饮食记录
- `calculate_pet_nutrition_target` - 计算营养目标
- `generate_pet_avatar` - 生成AI宠物形象（可选）
