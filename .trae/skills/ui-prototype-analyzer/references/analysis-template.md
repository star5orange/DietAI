## 模板使用说明

1. **页面名称**：格式为`{功能模块}-{页面名称}`，如"健康宣教-宣教任务列表"
2. **来源标注**：
   - `[UI图片]`：信息来自UI原型/截图
   - `[需求文档]`：信息来自需求文档
   - `[融合分析]`：基于两者综合推断
3. **UI元素分析**：按页面区域分组，每个区域用表格列出所有可见元素；同一区域元素较多时可拆分为多个子区域
4. **字段信息分析**：按信息类别分组，用标准表格列出所有字段属性；若字段为只读，在"字段状态说明"中统一说明
5. **业务关联说明**：重点描述该页面在业务流程中的位置，与前后页面的跳转关系，以及角色权限差异
6. **关联页面**：若多张图片属于同一页面或同一操作流程，合并为一个文档，在"关联页面"字段中注明，并在"前后交互关系"中用箭头（→）标注流转方向
7. **需求文档补充**：对于需求文档中提到的功能但UI图片中未展示的内容，在"需求文档补充说明"中记录
